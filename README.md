# Amazon Clone

This project is a high-fidelity replica of the Amazon e-commerce website, built using **Next.js**, **React**, and **CSS**.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.
- **Modern UI**: Replicates Amazon's iconic interface, including the hero section, product grids, and navigation.
- **Next.js Framework**: Leverages server-side rendering and efficient routing for optimal performance.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Library**: [React](https://reactjs.org/)
- **Styling**: Standard CSS

## Getting Started

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
